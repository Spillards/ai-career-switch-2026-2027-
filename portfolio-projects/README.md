# Portfolio Projects

**Status:** Planned scope — no integrated portfolio project is presented as completed yet.

## Planned evidence standard

A future portfolio project should make the following assessable by an outsider:

- business problem, stakeholder and baseline;
- requirements, constraints and acceptance criteria;
- solution choice and rejected alternatives;
- data and integration dependencies;
- implementation or prototype;
- evaluations, normal cases, edge cases and failure cases;
- controls, human responsibilities and fallback;
- limitations, lessons learned and reproducibility.

Projects will be added only after the corresponding AI content block is explicitly started and sufficient completed evidence exists.
