# Supporting Documentation

**Status:** Planned support area.

This folder is reserved for cross-project documentation that does not belong beside one specific artefact, such as reusable setup notes, diagrams or contribution guidance.

## Documentation rules

- keep evidence beside the work it supports whenever possible;
- avoid duplicating content that can drift;
- keep the glossary in Notion, not in this repository;
- never store secrets, credentials, personal data or confidential material;
- label drafts and planned material clearly.
