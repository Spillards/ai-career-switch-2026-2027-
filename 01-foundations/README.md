# 01 — Foundations

This folder contains the foundational work from the first phase of my
AI Career Switch 2026–2027.

The focus is not only on learning AI terminology, but on building the
ability to reason from a business problem to an appropriate solution,
identify the required data, assess risks and controls, and provide
evidence for the decision.

## Current scope

### Week 1 — Baseline, Git/GitHub and AI landscape

Focus:
- AI / ML / Deep Learning / Generative AI
- automation vs. ML vs. GenAI vs. agents
- Git and GitHub fundamentals
- solution-choice reasoning
- AI use-case framing
- Responsible AI baseline
- portfolio and evidence principles

Evidence produced:
- Git/GitHub exercises and repository setup
- solution-choice exercises
- AI use-case canvases
- Responsible AI risks and controls
- Portfolio Charter
- Market Signals / target-role analysis

## Week 2 — AI Fundamentals for Business

Focus:
- supervised vs. unsupervised machine learning
- features and labels
- data literacy
- tabular data, CSV and JSON
- data quality
- problem framing before selecting AI
- no-AI vs. ML vs. GenAI decisions
- value hypotheses
- failure cases, risks and controls
- AI go / no-go reasoning
